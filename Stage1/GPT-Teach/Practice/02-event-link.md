# Practice 1.2 — Hero 内部的 Events 链接

## 前置知识

阅读 [Links and IDs](../03-links-and-ids.md)。

## 需求

在 Hero 介绍段落下面添加一个可点击的文字链接：

- 显示文本：`Explore Events`
- 点击后跳转到同页面的 `Upcoming Events` 区域。
- 不引入 JavaScript。
- 本题先实现链接功能，**不要求按钮式 CSS 外观**。

## 验收标准

- 使用语义正确的 HTML 链接元素。
- 目标 Events 区域能被正确定位。
- 在浏览器中实测点击功能。
- 能解释 URL 片段（`#...`）与目标 ID 的关系。

## 提示

回忆你已经为 Events 区域设置了哪个 `id`，以及 `href` 应如何引用它。
