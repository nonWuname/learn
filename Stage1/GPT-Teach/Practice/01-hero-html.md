# Practice 1.1 — 组织 Hero 区域

**来源**：已学 HTML 文档结构与 Semantic HTML。

## 需求

在现有练习网站中，创建一个位于 Header 之后、Upcoming Events 之前的 Hero 区域：

- Hero 标题文本：`Build. Learn. Connect.`
- Hero 属于页面的主要内容 `main`。
- Upcoming Events 是另一个独立主题区域，标题为 `Upcoming Events`。
- 不使用不存在的 `<hero>` 标签。
- 这一题只处理 HTML 结构，不增加 CSS、按钮或图片。

## 验收标准

- `header` 在 `main` 前面，`footer` 在 `main` 后面。
- Hero 和 Events 各有合理的 `section`；标题层级合理。
- 所有起始 / 结束标签正常配对、嵌套正确。
- 能解释 `main` 与 `section` 的差别。
