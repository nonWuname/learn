# Web Development Learning Lab

A stage-based repository for learning web development through concept lessons, independently implemented challenges, personal summaries, and Git history.

## Roadmap

- **Stage 1 — Responsive Web:** HTML, CSS, and responsive design; independent mini-projects.
- **Stage 2 — Interactive Web:** JavaScript, DOM, browser interactions, and independent mini-projects.
- **Stage 3 — Deployment:** Testing, builds, hosting, deployments, and release practices.

Git, debugging, and code review are practiced across all stages.

The real Hanfu club website will be developed in a **separate product repository** when requirements are clarified. Codex or other coding agents can be considered for that project later.

## Repository Convention

Each stage has AI-authored reference material under `GPT-Teach/` and learner-authored implementations and summaries under `My-Work/`. New lesson files are not pre-generated.

See `WORKFLOW.md` for the review, approval, and commit policy.
