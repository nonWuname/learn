# Challenge 1.1 — First HTML Page

**Stage:** 1 — Responsive Web Development  
**Related lesson:** [HTML Introduction & Document Structure](../Lessons/01-html-introduction.md)

## Goal

Build a simple self-introduction webpage using **HTML only**. The learner must write and test the code independently.

## Requirements

1. Create a valid HTML5 document.
2. Set the primary document language to English.
3. Set the browser tab/document title to **My Web Journey**.
4. Add one first-level page heading: **My Web Development Journey**.
5. Add two separate paragraph elements:
   - **I am learning HTML.**
   - **My goal is to build a responsive website.**
6. Declare UTF-8 character encoding.
7. Do not use CSS or JavaScript for this challenge.

## Acceptance Criteria

- Appropriate document declaration, root, head, and body structure.
- Properly nested HTML tags.
- Correct document title visible in the browser tab.
- The visible content uses one heading and two separate paragraphs.
- Browser rendering is tested.
- The learner can explain the difference between `title` and `h1`, and the purpose of the encoding declaration.

## Deliverable

Write the page in:

`Stage1-Responsive-Web/My-Work/Exercises/01-first-page/index.html`

The learner owns the exercise solution and its commit. **This challenge does not contain the solution.**

## Review Notes

Use a short understanding check after the implementation, focusing only on adequately taught material. If a necessary concept was not fully explained, teach it before assessing it. GPT may prepare an English summary after review, but the learner must approve it before publication.
